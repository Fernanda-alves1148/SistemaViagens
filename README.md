# Sistema de Gerenciamento de Viagens

Aplicação web para gerenciamento de solicitações de viagens corporativas.

## Tecnologias

### Frontend
- React
- Vite
- JavaScript
- React Router
- HTML5
- CSS3

### Backend
- Java
- Spring Boot
- API REST

### Banco de Dados
- PostgreSQL

### Infraestrutura
- Docker
